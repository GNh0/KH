# Artifact checks

Compare final files with the requested content, format and destination. Use currently available document, spreadsheet, slide and PDF tools for appropriate creation/rendering. Inspect actual formulas, tables, report bands, pages and text readability.

Optional structural check: `python -B <plugin-root>/scripts/company_check.py artifact <absolute-file>`. Headers and ZIP/XML structure do not establish correct content or successful rendering. State the actual verified scope and deliver the requested final files. Clean task-owned temporary render/validation output using [workspace files](../work-execution/references/workspace-files.md).
