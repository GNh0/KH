# Work planning

현재 요청과 실제 입력으로 완료 결과를 먼저 정한다. 기존 계획과 승인된 선택은 이어서 사용한다. 결과를 바꾸는 모호성만 질문하고 답변과 무관한 조사는 계속한다.

필요한 경우 현재 구조, 변경 범위, 의존 순서, 검증 방법을 짧은 계획으로 남긴다. 특정 제목·점수·역할 조직도·문서 수를 채우는 것을 계획의 완료 조건으로 삼지 않는다. 이미 구현을 요청한 사용자에게 계획 서식 승인을 다시 요구하지 않는다.

스킬은 현재 제공된 목록에서 작업에 필요한 것만 선택한다. 과거 메모리·인계문에 적힌 하네스 목록을 선행 점검으로 재실행하지 않는다. 스킬 구성 감사나 목록 확인을 요청받은 경우에만 별도 탐색·선택표를 작성한다.

작은 명확한 질문이나 국소 수정은 직접 처리한다. PB 이관처럼 입력 관계가 중요한 계획에서는 해당 도메인 스킬의 원본 분석 지침을 사용한다. 최종 설명은 결과와 근거부터 전달한다.
