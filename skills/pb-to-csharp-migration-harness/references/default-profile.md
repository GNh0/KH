# Scoped default profile

[default-profile.json](default-profile.json) supplies default choices from user WinForms/DevExpress/KoneLib patterns identified in audits. It does not replace actual types, APIs, business values, or screen dimensions. Prioritize current user corrections and the specified comparison screen; do not repeat author discovery for ordinary tasks.

For maintenance requests creating new profiles, follow [profile maintenance](../../kh-maintenance/references/pb-profile-maintenance.md). Record names, scope, and explicit defaults without requiring signatures or execution receipts. Preserve raw fields of composite keys with any number of components and declare actual numeric types. CONVERT may be used for integer display; do not mechanically replace FORMAT where decimal or formatting semantics differ.
