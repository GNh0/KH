# 범위별 기본 프로필

[default-profile.json](default-profile.json)은 감사에서 확인한 WinForms/DevExpress/KoneLib 사용자 패턴의 기본 선택이다. 실제 타입·API·업무 값·화면 크기를 대신하지 않는다. 현재 사용자 정정과 지정 비교 화면을 우선하고, 일반 작업마다 작성자를 재검색하지 않는다.

새 프로필을 만드는 유지보수 요청에는 [프로필 유지보수](../../kh-maintenance/references/pb-profile-maintenance.md)를 따른다. 이름·범위·명시적 기본값을 기록하며 서명·실행 영수증을 요구하지 않는다. 임의 개수 복합키의 원시 필드를 보존하고 실제 숫자 타입을 선언한다. 정수형 표시에는 CONVERT를 쓸 수 있으며 소수·포맷 의미가 다른 FORMAT을 기계적으로 바꾸지 않는다.
