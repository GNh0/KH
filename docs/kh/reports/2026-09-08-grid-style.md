# KH 3.0.2 그리드 기본값과 편집 규칙

사용자가 사용하지 않는 셀 정렬, SpinEdit 마스크, DisplayFormat, GridView 전체 편집 잠금이 다른 작업에서 생성됐다. 3.0.2는 사용자가 제공한 DataWindowToXml.html의 Load Layout 기본 속성과 직접 정정한 컬럼 편집 규칙을 C#/PB 스킬·프로필·생성기·검사기에 함께 반영한다.

## 확인한 원인

참조 작업의 원문에는 3.0.1 C# 스킬, designer.md, default-profile.json을 실제로 읽고 성공한 도구 출력이 있다. 이어 해당 작업의 자체 화면 생성 코드에서 OptionsBehavior와 셀 TextOptions 등이 추가됐다. 스킬 선택 실패만으로 설명할 수 없다.

3.0.1 문서는 셀/헤더 정렬이 다르다는 설명과 불필요한 DisplayFormat.FormatString을 피하라는 일반 지침만 담았다. 정확한 속성 생략 기준, FormatType, 편집 세 가지 구분과 OptionsBehavior 보존 기준은 없었다. 검사기도 이 항목들을 확인하지 않았다. PB→C# 초안 생성기는 기본으로 AllowEdit=false만 출력했고 ReadOnly=true를 함께 출력하지 않았다. 그 생성기 자체가 SpinEdit 마스크나 OptionsBehavior를 출력한 것은 아니다.

## 적용한 동작

- 새 그리드는 [사용자 HTML 기준](../../../skills/csharp-designer-style-harness/references/grid-layout.md)을 사용한다. 원본 JavaScript 함수를 일반 예시 입력으로 실행한 XML을 fixture로 보존했다. 기존 XML 생성값은 일치했고, C# 생성기에서 추가되던 기본 편집 잠금을 제거했다.
- 셀은 UseFont만 설정하고 TextOptions/UseTextOptions를 생략한다. 헤더는 UseFont/UseTextOptions와 가로·세로 Center를 적용한다. HTML의 Tahoma 9pt는 새 그리드 템플릿 값이며 기존 사용자가 바꾼 폰트는 보존한다.
- 일반 편집 차단은 AllowEdit=false와 ReadOnly=true, 버튼 등 동작 유지 컬럼은 ReadOnly=true만, 편집 가능 컬럼은 둘 다 생략한다. 생성과 검사에서 명시한 컬럼 모드를 같은 계약으로 사용한다.
- OptionsBehavior를 기본 추가하지 않고 기존 값을 보존한다. 원본 대비 추가·변경·삭제를 검토하며, 컬럼 제어를 뷰 전체 제어로 확대하지 않는다.
- SpinEdit EditMask와 DisplayFormat.FormatType/FormatString은 기본으로 추가하지 않는다. DateEdit 입력 마스크, 보고서 서식과 기존 설정을 일괄 삭제하는 규칙으로 확대하지 않는다.
- HTML 밖 뷰/컬럼 옵션은 필요한 동작이 있는지 검토한다. 정확한 속성 단위의 현재 요구를 전달할 수 있고, 일반 스타일 경고는 구현 차단이나 별도 승인 절차가 아니다. 명시한 편집·보존 계약의 모순은 오류다.

## 검증 결과

총 137개 단위 검사를 Python 3.12·3.14에서 통과했다. 3.0.1보다 24개가 추가됐다. 최초 반례에서 기본 잠금·편집 구분·스타일 누락을 재현하고 수정했다. 검토 중 삭제된 비그리드 컨트롤의 원본 타입을 잘못 추론하는 반례도 재현해 수정했다.

Pyright 1.1.413은 54개 파일에서 오류·경고 0건이다. 공식 플러그인 검증, 10개 스킬 검증, 패키지 링크/내부 import 검사와 Python 3.11 문법 검사도 통과했다. 타입 검사 모드나 기존 검사 범위는 완화하지 않았다.

독립 에이전트에는 수정된 스킬 경로, 최소 부분 클래스 두 개와 실제 작성 요청만 전달했다. 기존 컬럼 캡션을 수정하면서 새 일반 보호/버튼/편집 가능/날짜 컬럼을 작성한 결과, 요청한 편집 구분·버튼 이벤트 연결·새 옵션 생략·기존 폰트/정렬/OptionsBehavior 보존을 확인했다. 구현자의 기대 답안이나 이전 결론은 전달하지 않았다. 이 결과는 한 번의 정적 사용 평가이며 향후 모든 작업의 준수율이나 실제 버튼 클릭 성공률을 뜻하지 않는다.

참조 업무 프로젝트는 읽기 전용으로 확인했다. 현재 소스에서 요청한 다섯 종류의 검토 항목이 잡히는 것도 확인했으며, 원본 없이 나온 경고 수를 무단 변경 수로 단정하지 않는다. 업무 소스 수정, ERP 빌드, Designer 렌더링, DB/PB 실행은 수행하지 않았다. 원래 있던 미추적 파일 25개는 보존하고 공개 패키지에서 제외했다.

검증 상세는 [결과 JSON](2026-09-08-grid-style.json)에 있다. 원격 GitHub 실행과 설치된 캐시 상태는 게시 후 별도로 확인한다. 새 소스가 기존 실행 중 작업의 로드된 지침을 자동 교체하지는 않는다.
