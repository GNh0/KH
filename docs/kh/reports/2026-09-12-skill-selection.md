# KH 3.0.8: 스킬 선택과 인계

과거 메모리·인계문의 하네스 목록과 캐시 경로를 따라 현재 패키지에 없는 스킬을 검색하거나 사용 여부 표를 만드는 작업을 줄인다.

- `work-planning`은 미해결 설계 선택이나 의존 관계가 있는 큰 작업에 적용한다. 단순 질문·국소 수정·이미 충분한 계획이 있는 작업은 제외한다.
- 일반 작업은 현재 제공된 스킬 중 필요한 것만 선택한다. 구형 하네스 목록의 선행 점검과 스킬 선택표는 요청한 구성 감사·목록 확인 범위에서만 다룬다.
- `context-handoff`는 현재 세션의 스킬 경로를 사용하며, 제거된 하네스 검색을 인수인계 단계에 추가하지 않는다.

기존 도메인 규칙, 프로젝트별 배포 검사와 스킬의 암시적 호출 설정은 유지한다. 개인 메모리 저장소는 플러그인과 별도이며 이 배포가 사용자 메모리 파일을 변경하지 않는다.

검증 범위는 수정한 두 스킬의 형식, 플러그인 manifest, Markdown 참조와 Python 구문·내부 import 구조다. 실제 작업의 호출 횟수나 소요 시간 개선은 이 정적 검사로 입증하지 않는다.
