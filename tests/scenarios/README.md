# 스킬 시나리오 평가

[cases.json](cases.json)의 36개 요청은 실제 스킬 사용 평가용이다. 모든 항목을 자동으로 성공 처리하는 라우터나 점수 계산기는 없다.

입력과 사용자 요청을 독립 평가자에게 전달하고 필요한 SKILL.md만 읽게 한다. 실제 답변·최종 파일·부작용·도구 결과·미확인 범위를 검토한다. 현재 호스트에서 위임이 허용될 때만 독립 에이전트를 사용한다. root 작업의 계획·정답·이전 실패 내용을 평가자에게 미리 주지 않는다.

`fixtures`는 SQL 정리와 C# 포커스 행 평가에 사용한 최소 입력이다. 결과 정답은 입력에 넣지 않았다. 이들은 실제 ERP 실행 환경이 아니다.

`local_check_files`는 관련 단위/모의 검사 위치이며 시나리오 전체의 실행 증거가 아니다. `not_executed_in_a_real_host` 항목을 통과로 해석하지 않는다. 실제 두 독립 사용 평가와 native Goal 관찰은 [구현 결과](../../docs/kh/reports/2026-09-07-codex-implementation.md)에 연결되어 있다.
