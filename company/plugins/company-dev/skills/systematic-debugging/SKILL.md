# Systematic debugging

Identify the exact current files, procedures, environment and failure stage. Separate observations from hypotheses. Read the actual execution path and test a minimal causal comparison.

Measure database execution, transfer, binding and UI layout costs separately where relevant, using comparable inputs and row counts. Inspect actual output and reproduction behavior rather than exit codes alone. Fix the affected scope and recheck the original failure. Do not repeat unchanged checks or a failed hypothesis without new evidence. Follow [workspace files](../work-execution/references/workspace-files.md) for probes and cleanup.
